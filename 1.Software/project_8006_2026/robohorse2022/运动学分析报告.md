# RoboHorse2022 运动学分析报告

## 1. 硬件平台概览

| 组件 | 型号 | 说明 |
|------|------|------|
| MCU | STM32F427xx | Cortex-M4, 180MHz, FPU |
| 电机 | DM-J8009 ×8 | 达妙无刷电机, CAN总线, MIT模式 |
| IMU | JY901S | 9轴姿态传感器, UART8 DMA |

## 2. 运动学数据流

```
遥控器 (100Hz)
  │  SBUS解析 → my_rc_ctrl
  │  Ctrl_byRemoctrl() 更新步态参数
  ▼
Posture_Task (100Hz, 10ms周期)
  │
  ├── 路径A: 行走步态 ──────────────────────┐
  │   Calculate_Gait()                       │
  │   → Cycloid_Generator_Calc() ×4          │
  │   → 输出 aim_x[4], aim_y[4] (直角坐标)    │
  │                                          ▼
  │                              Target_toMotor()
  │                              → IK解算
  │                              → 除以 MOTOR_ANGLE_SCALE(0.5)
  │                              → Aim_Angle[8]
  │
  ├── 路径B: 跳跃/手动 ──────────────────────┐
  │   极坐标 (r, θ)                          │
  │   → Polar_setCoord()                     │
  │   → Polar_toCartesian()                  │
  │   → IK解算                               │
  │   → 不除以 MOTOR_ANGLE_SCALE             │
  │   → Aim_Angle[8]                         │
  │                                          │
  ▼                                          ▼
Motor_Task (500Hz 目标, 实际约125Hz)
  │  位置环 PID_Position[8]: angle_err → vel_target
  │  速度环 PID_Speed[8]:    vel_err   → torque
  ▼
CAN1 + CAN2 → 8个 DM-J8009 电机
```

## 3. 坐标系统

### 3.1 极坐标 `Polar_Coord_Data_t`

```c
typedef struct {
    float radius;  // 髋关节到足端的直线距离 (cm), 范围 6~26
    float theta;   // 腿与垂直方向的夹角 (度)
                   // 负值 = 腿在身后, 正值 = 腿在身前
} Polar_Coord_Data_t;
```

### 3.2 直角坐标 `Cart_Coord_Data_t`

```c
typedef struct {
    float cx;  // 足端前后位置, 相对髋关节 (cm)
    float cy;  // 足端上下位置, 相对髋关节 (cm)
} Cart_Coord_Data_t;
```

### 3.3 坐标转换

```c
cx = radius × sin(theta × π/180)   // 前后分量
cy = radius × cos(theta × π/180)   // 上下分量
```

**身体离地高度估算**: `h ≈ r × cos(θ)`（θ 较小时近似等于 r）

### 3.4 站立时示例

| 场景 | r (cm) | θ (°) | 身体高度 (cm) |
|------|--------|-------|-------------|
| 平地跳下蹲 | 12.0 | -22° | ~11.1 |
| 平地跳起跳末 | 23.0 | -18° | ~21.9 |
| 平地跳落地稳 | 17.5 | 3° | ~17.5 |
| 上坡跳起跳末 | 26.0 | -15° | ~25.1 |

## 4. 逆运动学 (IK)

### 4.1 算法

文件位置: `Algorithm/Bionics/robohorse/stanford_type.c`

使用 **2连杆精简模型**（完整6连杆模型未完成，标注了 FIXME）:

```
输入: (x, y) 足端相对髋关节的坐标

步骤:
  l   = √(x² + y²)                           // 髋到足端的距离
  ψ   = arcsin(x / l)                         // 足端矢量与垂直方向的夹角
  φ   = arccos((l² + L1² - L2²) / (2·l·L1)) // 余弦定理求膝关节角

输出:
  angle[0] = ψ - φ    // 髋关节角 (内侧电机)
  angle[1] = ψ + φ    // 膝关节角 (外侧电机)
```

### 4.2 关节角到电机角度

```c
angle_inner = π/2 + angle[0]   // 内侧电机 (hip)
angle_outer = π/2 - angle[1]   // 外侧电机 (knee)
```

### 4.3 ⚠️ 已知问题

完整版 IK 源码中有 FIXME 注释: "还没完工，网上提供的公式好像有问题"。目前只有精简版可用。

## 5. 摆线(正弦)轨迹生成

文件位置: `Algorithm/Bionics/robohorse/cycloid_generator.c`

> ⚠️ 源码注释自嘲: "抄完发现是正弦轨迹生成器"——并非真正的摆线。

### 5.1 输入参数 `Cycloid_Generator_Param_t`

| 参数 | 含义 | WALK 典型值 | TROT 典型值 |
|------|------|------------|------------|
| `body_height` | 身体离地高度 (cm) | 20.3 | 14.0 |
| `step_length` | 步幅 (cm) | 7.3 | 6.0 |
| `up_amp` | 抬腿高度 (cm) | 6.5 | 2.5 |
| `freq` | 步频 (Hz) | 0.1 | 0.1 |
| `fly_ratio` | 摆动相占比 | 0.45 | 0.5 |

### 5.2 轨迹公式

**摆动相** (腿在空中, `phase ≤ fly_ratio`):
```
x = (phase / fly_ratio) × step_length - step_length/2    // 线性前移
y = -up_amp × sin(π × phase / fly_ratio) + body_height   // 正弦弧线抬起
```

**支撑相** (腿在地面, `phase > fly_ratio`):
```
x = -percent × step_length + step_length/2               // 线性后推
y = down_amp × sin(π × percent) + body_height            // 轻微正弦下压
```

### 5.3 相位分配 (对角步态)

| 步态 | 腿0 (左前) | 腿1 (左后) | 腿2 (右后) | 腿3 (右前) |
|------|-----------|-----------|-----------|-----------|
| WALK | 0.51 | 0.01 | 0.51 | 0.01 |
| TROT | 0.51 | 0.01 | 0.51 | 0.01 |
| CLIMBING | 0.51 | 0.01 | 0.51 | 0.01 |
| TURN_LEFT | 0.51 | 0.76 | 0.26 | 0.01 |
| TURN_RIGHT | 0.01 | 0.26 | 0.76 | 0.51 |

> 腿0+2 同相、腿1+3 同相（相差半个周期 = 对角步态）
>
> ⚠️ FIXME: phase=0 会导致某条腿卡死，所以所有相位都加了偏移

## 6. 腿部 → 电机映射

每条腿2个电机 (内侧 hip + 外侧 knee)，共8个:

| 腿编号 | 位置 | 内侧电机 | 外侧电机 | CAN总线 |
|--------|------|----------|----------|---------|
| Leg 0 | 左前 (LF) | Motor 2 | Motor 3 | CAN2 |
| Leg 1 | 左后 (LR) | Motor 4 | Motor 5 | CAN2 |
| Leg 2 | 右后 (RR) | Motor 6 | Motor 7 | CAN1 |
| Leg 3 | 右前 (RF) | Motor 1 | Motor 0 | CAN1 |

### 6.1 Target_toMotor() — 行走步态映射

```c
// 左侧 (腿0,1): 角度取负
Leg 0 (左前):  Aim_Angle[3] = -(π/2 - angle[1]) / 0.5   // 电机3 (外)
              Aim_Angle[2] = -(π/2 + angle[0]) / 0.5   // 电机2 (内)

Leg 1 (左后):  Aim_Angle[5] = -(π/2 - angle[1]) / 0.5   // 电机5 (外)
              Aim_Angle[4] = -(π/2 + angle[0]) / 0.5   // 电机4 (内)

// 右侧 (腿2,3): 角度取正
Leg 2 (右后):  Aim_Angle[7] = +(π/2 - angle[1]) / 0.5   // 电机7 (外)
              Aim_Angle[6] = +(π/2 + angle[0]) / 0.5   // 电机6 (内)

Leg 3 (右前):  Aim_Angle[0] = +(π/2 - angle[1]) / 0.5   // 电机0 (外)
              Aim_Angle[1] = +(π/2 + angle[0]) / 0.5   // 电机1 (内)
```

**符号规律**: 左侧全负、右侧全正 — 补偿左右腿的机械镜像安装。

### 6.2 Polar_setCoord() — 跳跃映射

同样模式，但有两点不同:
1. **不除以 `MOTOR_ANGLE_SCALE` (0.5)** — 跳跃时角度值是行走的一半
2. **跳跃时 Leg 0 和 Leg 2 翻转符号** — 保证四条腿朝同一方向运动

## 7. 双环PID控制

Motor_Task 以 500Hz 目标频率运行（实际约125Hz，CAN延迟导致）:

```
编码器反馈 (encoder ticks 0~8191)
    │
    ▼
位置环 (PID_Position):  angle_err → vel_target (上限 ±720 RPM)
    │
    ▼
速度环 (PID_Speed):     vel_err → torque (上限 ±18 N·m)
    │
    ▼
CAN MIT模式帧: set_pos + vel_target + KP + KD + torque
    │
    ▼
DM-J8009 电机执行器
```

各状态 PID 参数 (kp_pos / kd_pos / kp_spd / kd_spd):

| 状态 | 位置Kp | 位置Kd | 速度Kp | 速度Kd | 特点 |
|------|--------|--------|--------|--------|------|
| STOP | 22.0 | 1.0 | 10.0 | 0.15 | 超硬位置锁定 |
| WALK | 14.0 | 0.4 | 18.0 | 0.06 | 均衡 |
| TROT | 10.0 | 0.15 | 25.0 | 0.02 | 速度优先 |
| BRIDGE | 20.0 | 0.8 | 12.0 | 0.1 | 位置优先 |
| CLIMBING | 18.0 | 0.5 | 16.0 | 0.08 | 偏硬 |

## 8. IMU 姿态校正

AHRS_Task (100Hz) 读取 JY901S 数据:

**Roll 补偿** (左右平衡):
- `imu_Leg_offset = roll_angle` (限制 ±22°)
- 在 Motor_Task 中加到左右腿目标角度，符号相反

**Yaw 补偿** (前后平衡):
- PID 控制 `step_len_dev`
- 前腿步长减 `step_len_dev`，后腿步长加 `step_len_dev`
